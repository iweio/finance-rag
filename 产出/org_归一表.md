# org 归一表

按 `、` 拆开的机关取值从 **34 个降到 23 个**，改了 11 行。

**只并异写，不并前身/继任**——`中国银行保险监督管理委员会`（2018-2023）与
`国家金融监督管理总局`（2023- ）是两个机构，各自保留。
