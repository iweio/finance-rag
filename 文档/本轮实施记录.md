## 5. 已知取舍与风险

1. **契约 8→10**：`/auth/*` 是扩展接口，`契约/README.md` §4 #16 记了「需 P1 签字」。
   签字前不要在验收材料里写「10 个接口」。
2. **匿名策略**：后端允许匿名收藏/历史（`user_id=NULL`），前端 mock 与路由**要求登录**（更严）。
   两者不矛盾，但演示时如果绕过前端直接调接口，匿名也能写——这是为了不破坏 8 个既有接口的契约。
3. **数据层仍是 v4 口径**：`产出/chunks` 8156 行、**0 个 table chunk**（SPEC v5 未重跑）。
   `/health` 的 `row_count` 在真机会是 8156；重跑后要更新文档数字。
4. **前端依赖版本**：`vite ^6` + `unplugin-auto-import ^0.18` / `unplugin-vue-components ^0.27`，
   若 `pnpm install` 报 peer 冲突，升到 `^19` / `^28`。
5. **Element Plus 样式**：为保险在 `main.ts` 全局引了 `element-plus/dist/index.css`（多 ~300KB），
   组件 JS 仍按需引入。
6. **compose 首启慢**：backend 要 import torch + 加载模型，`start_period` 已给 120s；
   模型权重走 `model_cache` 卷，第一次仍需联网下载。
